## 2. WP2 — rule 5 repair (Writer A)

**Files:** `src/transgenic/evidence/b6_corpus_repair.py` (imports `build_b5`/`gsf_contract` read-only), `revision/scripts/evidence/b6_build_corpus.py` (`--base b5_full_a40_v1.db --splits --flags --build-flags --seed --measure-only|--apply --out b5_full_b6_v1.db --freeze <json>`, exclusive output), `b6_validate_corpus.py` (independent recomputation), `tests/test_b6_corpus_repair.py`.

**Method.** Copy A40 and update rows in place without re-tiling, so `rn`, `wid`, order and coordinates stay A40's.
1. **Population (D1).** For each kept train/valid forward tile, take the edge-crossing genes (`partial` of `gc.genes_in_window`). Apply the build's own `leak` and `hard` predicates to them (`build_b5.py:567`, `:569`). Decoy is not applied.
2. **Closure, no partial mask (A33.3).** Mask the whole overlap component (`inside ∪ partial`) of every edge seed. A labelled inside gene in such a component is **unlabelled**. The builder regenerates `gff` with `gc.window_to_gsf_v3` over the remaining labelled genes, recomputes tokens, `n_transcripts` and `qc`, deletes the gene's `window_genes` rows and counts a `closure_label_drop`.
3. **Flank (seeded 50–150, never fixed 150).** Each newly masked gene gets `randint(50, 150)` from `random.Random(f"{seed}:{species_id}:{chrom}:{ws}-{we}:b6edge")` in (start0, gene_id) order, clipped to the tile. The separate key leaves the build's `:flank` stream (`build_b5.py:597`) untouched. The 150 in `leakage.py:12` is an exclusion bound, not a mask rule.
4. **RC twin.** The twin is `revcomp` of the repaired forward tile, and its GSF is `gc.reverse_complement_v3` of the regenerated GSF.
5. **Row-changing events.** A repaired train/valid tile with masked fraction > 0.60 (`build_b5.py:602`) must be dropped. Closure can also remove the last labelled gene of a tile that had an RC twin. Both change the row set.
6. **Measure first.** `--measure-only` writes counters and changes nothing. `--apply` refuses to run if either row-changing count is non-zero, because the train-row count then leaves 198,828, the basis of **N_pilot = 4,142** (P:999). **A further amendment is then required**, and N_pilot is never redefined in code. Label drops alone keep the rows and are applied.

**Outputs.** The B6 DB gains `b6_dna_repair(rn, wid, species_id, chromosome, start0, end0, gene_id, role, flank, is_rc)` and `b6_label_drop(rn, gene_id, cause)`. The freeze JSON records `base_sha256` (A40), `out_sha256` (one sha for B6 and its comparator), code sha, seed, input shas, flank key, rule id `rule5-leak-hard-v1`, counts by species × split × cause, and row counts.

**Acceptance.** The frozen byte identity is **B6 versus its comparator** (one file, same `rn` order). The A40 comparison is an exact declared-change audit: every sequence difference is ACGT→N inside a repair span, every GSF/`window_genes`/`qc` difference is a `b6_label_drop` row, and test tiles never change. Repair bases outside the tile's rule-4(a) intervals are reported, not failed, because counts are zero at N.
- **Synthetic world** (`tests/test_b6_c0_world.py`): the gL edge spans are masked, and a fixture overlap triggers a closure drop.
- **Also:** forward/RC consistency, two byte-identical rebuilds, and 198,828 train rows on the real run (pronghorn A40 DB, which needs no C0).

## 5. WP2b — `evlabel` builder (Writer A, off the critical path)

**Files.** `src/transgenic/evidence/b6_evlabel.py`, `revision/scripts/evidence/b6_build_evlabel.py`, `b6_validate_evlabel.py`, `tests/test_b6_evlabel.py`. A test asserts that no B6 module imports it and that the B6 trainer refuses it.

**Inputs, each sha-verified:** the merged snapshot (§8), the protein supplements, the B6 corpus + freeze, and the roles sha.

**Population.** Accepted primaries that are `training_eligible` and `train_track`, from the A37 primary EST arm (never ≥ 121). Only train and valid tiles receive cells: train tiles need `train_tiles_excluded = false`, and valid tiles admit it. Protein queries must not be leakage-excluded. Cells on N bases are dropped.

**Cells.** Tile-local, 0-based. Unsupported cells are weight 0 and absent.
- **Intron family.** Source: accepted, canonical `junction_observation` on strand ± joined to `junction_support`, with `train_track`, `excluded_4c = false`, and no `excluded_junction_coordinate` hit.
  - Cells: `intron` over [min, max] of (donor0, acceptor0); `splice_donor` at C0 `donor0`; `splice_acceptor` at `acceptor0`. These are strand-aware (on −, donor0 > acceptor0, `c0_schema.py:13-20`).
  - Implementation: own `junction_cells()`. **Never** `gsf_contract.add_junction_evidence` (`:526-531`), which labels the lower coordinate as donor.
  - `n` = A11/A16 units in the population, library-capped, cross-checked against `junction.n_molecules_library_capped`. Weight via `junction_weight` (EST 1.0 / PacBio 0.9 / ONT 0.7). Protein introns need ≥ 2 organisms and weigh 0.5.
- **Exon.** `aligned_block` gives `exon` with `evidence_weight(family="exon")` (PacBio 1.0 / ONT 0.8 / EST 0.6) and per-base units. Retained-intron bases get 0.25 (a block spanning an intron with ≥ 3 units while the block itself has < 3).
- **Protein CDS.** Accepted, non-ambiguous placements label `protein_coding_gene` only (source weight 1.0, n = organisms). Phase is not a class and goes to `evlabel_phase`.
- **UTR (A50/A50.1).** Use same-strand placements whose every CDS block lies in a read block and whose CDS introns equal the read's introns over the CDS span.
  - With one distinct (start, stop): read bases 5′ of the start codon get `5UTR`, and bases 3′ of the stop get `3UTR`.
  - A side the placement leaves incomplete stays neutral (`*_blocked_incomplete_orf`).
  - Two or more distinct starts or stops leave the whole read neutral (`*_blocked_conflicting_cds`).
  - EST contributes interior bases only.
  - The 14 classes lack TSS/TES, so v1 emits no boundary cell (policy `boundary_cells_not_emitted_v1`). A future one needs WP2c 5C/3C codes.
- **Merging.** Max across sources. Weight = `min(4, 1 + sw·g·log1p(n))`. Genotype mapping per D10.

**Output.** `evlabel_b6_v1.db` with `evlabel_cell(rn, class_index, start0, end0, weight, source, family, rule)`, `evlabel_phase`, `evlabel_qc` and `evlabel_provenance` (input shas, `EVLABEL_SPEC_SHA`). RC twin rows are explicit (p → L−1−p, class kept, strand swapped). `to_dense(rn, unit_weight)` returns f32[L,14] labels and weights; `unit_weight=True` is the mandatory ablation.

**QC** per species × source: the eight A50/A50.1 UTR counters, one cell count per class family, `junctions_dropped_excluded_4c`, `cells_dropped_masked_dna`, `molecules_used` and `longread_utr_boundary_cells`.

**Tests** cover every rule above: minus strand, RC twice, each neutrality case, EST interior, weights, retained intron, populations, masked DNA, unit weight and a byte-identical rebuild. The validator recomputes 1 % of tiles independently.

### 7.1 Track spec (K = 31, P:992)
- **Channels.** For source s ∈ (EST, ONT, PacBio), channels 8s…8s+7 are `cov+, cov−, cov?, donor+, acceptor+, donor−, acceptor−, mask`. Channel 24 is protein CDS log1p(organisms), unstranded. Channels 25–30 are phase (0,+),(1,+),(2,+),(0,−),(1,−),(2,−).
- **Values.** Coverage is log1p(molecules) clipped at log1p(64). Donor and acceptor values are log1p(molecules) on the boundary base. Everything is float16.
- **RC** (`new[c] = old[perm[c]]`, then reverse L). Each source block uses the frozen `[1,0,2,5,6,3,4,7]` (+8s). Channel 24 is identity. The phase block is `[28,29,30,25,26,27]`: strand swapped, label kept (P:992; Kimi 2–3 refuted).
- **Mask.** 1 iff the species has an admitted library of that source in the population. It stays 1 at fraction 0, is never zeroed at N (counts are), and stays 1 while any library of the source remains. It is 0 only under source withholding or tile dropout.
- **Zeroing.** After rasterisation, all six phase channels are zeroed over the population's zero list (A48).
- **C4 binarisation.** Count channels become 1.0 where > 0; masks are unchanged.

### 7.2 Chain spec and `chain-rc-v1`
- **Elements.** 512 elements. Element 0 is the dummy, with mask False, `chain_idx` 0 and zero features.
- **Slots (D9).** Chains occupy slots 1…63 (**63 usable**), and `E_slot` row 0 is dummy-only. Elements 1…511 fill chain by chain, each carrying `slot = π(fill_rank)`, where π is the argsort over slots 1…63 of `blake2b(f"{aug_seed}\t{rn}\t{epoch}\t{slot}")` (epoch 0 at evaluation).
- **`chain_feat`** = (`order_fwd`, `order_rev` ≤ 31 in transcription direction, `slot` 0…63, `source` 0/1/2, `strand` 0 + / 1 −, `units_bin = min(units, 64)`).
- **Fill.** Long reads first (units ↓, introns ↓, then `blake2b(f"{species}\t{strand}\t{intron list}", 8)` big-endian ↑), then EST. A chain that does not fit is dropped whole, and truncations are counted per source. Identical chains merge within a source (D8).
- **`chain-rc-v1`**, written in the spec and hashed: p → L−1−p; roles kept; strand swapped; order **unchanged** (rule 6a); slot and source unchanged. Twice = identity.
- **`CHAIN_SPEC_SHA`** covers every rule 9 item (P:997), including the §9 projections and `chain-rc-v1`.

### 7.3 Draws, shared by tracks and chains
- **Rank per draw.** Shards store `molecule_id` and never a rank. At load, the rule 8 rank is computed, vectorised, for each requested `aug_seed`: 20260914 + seed for training (seed 123 gives 20261037), and 20260914 + d for dose-response draw d ∈ 0…4.
- **Draws.** `u(purpose) = int.from_bytes(blake2b(f"{aug_seed}\t{purpose}\t{rn}\t{epoch}".encode("utf-8"), digest_size=8).digest(), "big") / 2**64`. Purposes are frozen as `dropout, fraction, withhold_source, withhold_source_pick, withhold_library, withhold_library_pick`.
  `dropped = u < 0.5`; `fraction = {0.01, 0.1, 0.5, 1}[⌊4u⌋]`; withholding applies at 0.1 of kept tiles, picked over sorted present sources or libraries. A non-numeric purpose cannot collide with the slot key. No `torch.Generator` is used, which replaces `datasets.py:336-345` ("not exact resume").
- **Sharing.** One `DrawSpec` per (rn, epoch) feeds both `rasterise` and `build_chains`. EST withholding also removes the phase channels. Protein follows D7.
- **Epoch propagation.** `B6EpochSampler` wraps the B5 order and yields (rn, epoch), so persistent workers hold no state.

### 7.4 Leakage context
Only `b6_bindings.tile_context(corpus, rn, mode)` builds `TileContext(rn, wid, species, chrom, ws, we, L, is_rc, tier, split, population, tile_exclusions, excluded_junctions, dna_n_mask, zero_intervals, roles_scope)`. The split comes from the corpus row.
- **Populations.** `train_track` covers train tiles, excluding train-tiles-excluded molecules. `valid_track` covers valid tiles and admits them. `eval_input` is A. thaliana `excluded_heldout` molecules of `b6_input` datasets (A-EST, A-ONT2) at the loci they touch, plus Z. mays M-EST and M-HQ18. Test tiles are refused for the training-side populations.
- **Chain splitting.** Train and valid tiles split at 4(c) junctions, rule 4(a) tile intervals (including `edge_partial`), non-accepted junctions (recorded reading) and tile edges. Evaluation windows split at window edges only. `tracks_only` datasets (M-HQ18) are never chained.
- **`b6_score`** molecules raise a hard error **in any training tile or evaluation input window**.
- **Zero lists per population (D4).** The producer at T drops train-tiles-excluded rows (`b6_routea_agreement.py:20-40`) and so covers `train_track` only. `--population` yields three static, sha-bound lists without b6_score molecules.
- **C3 donor (D6).** Forward rows are sorted by `blake2b(f"{aug_seed}\tc3\t{tier}\t{split}\t{wid}")` and each is paired with the next, cyclically. The result is fixed, within (tier, split), and has no fixed point. Twins share the donor. The donor's forward evidence (31 channels + chains) is rasterised under the **recipient's** DrawSpec and RC-transformed iff the recipient is RC.

### 7.5 Observation cache
- **Families.** Separate `train` and `eval` families, one parquet shard per (species, chrom). Loaders check the family.
- **Rows.** Every row carries the identity columns `species, source, dataset, run, library, molecule_id, molecule_key, molecule_state, train_tiles_excluded, role, b6_input, b6_score, b6_input_scope`. Track rows add `kind, strand, phase, protein_source, start0, end0, unit_id`. Chain rows add `placement_id, strand, introns[(donor0, acceptor0)], junction_keys, units_key`.
- **Filtering at build time,** with counts per species × source × population × cause in the manifest. Dropped rows: `never`, `b6_score`, non-input `validation_only`, `excluded_heldout` outside `eval_input`, the ≥ 121 arm, audit and secondary placements, unaccepted rows and excluded protein queries.
- **Manifest** binds every shard sha256, the evidence DB, B6 corpus, roles and zero-list shas, the three spec shas, the code sha and the family.

### 7.6 Library contracts
```python
rasterise(cache, ctx: TileContext, draw: DrawSpec) -> np.ndarray                     # float16 [L, 31]
build_chains(cache, ctx, draw) -> ChainTile   # chain_pos int32[512,2], chain_feat int16[512,6], chain_mask bool[512], qc
```
`chain_pos` is window-local C0 (donor0, acceptor0) with 0 ≤ p < L. It is internal to the library.

### 7.7 Batch contract (exact keys)

| key | dtype[shape] | rule |
|---|---|---|
| `input_ids` | int64[B, Lmax] | left-padded (`datasets.py:835-842`) |
| `attention_mask` | B5 collate dtype [B, Lmax] | left-padded, 1 = real |
| `evidence_tracks` | float16[B, Lmax, 31] | left-padded zeros |
| `labels` | int64[B, T] | decoder GSF tokens; T is independent of L; right-padded with −100 as B5 (`datasets.py:851-855`) |
| `chain_idx` | int64[B, 512, 2] | collate computes `(pad_b + 0 + chain_pos) // 6` as one sum, then one division (pad 1, p 5 gives 1); 0 when masked; asserted < Lmax/6 |
| `chain_feat` | int16[B, 512, 6] | cast to int64 before embedding |
| `chain_mask` | bool[B, 512] | True = real; column 0 always False |
| `meta` | dict | rn, epoch, arm, dropped, fraction, withheld source/library, draw-log hash |

The batch carries `chain_idx` and never `chain_pos`. Lmax and every tier length are multiples of 6, which the collate asserts.

**Labels stay right-padded on purpose.** The per-nucleotide tensors and the `chain_idx` offset share the input side. `labels` are decoder tokens for a causal decoder that starts at BOS, and left-padding them would break B5/C1 comparability. Kimi finding 5's per-base reading does not apply to them.

## 9. WP4 — model, benches, runtime, trainer (Writer C)

**Files.** `src/transgenic/model/modeling_b6.py`, `revision/scripts/b6/bench_memory_129k.py` + `.sbatch`, `src/transgenic/training/b6_runtime.py`, `train/train_HyenaTransgenic_B6.py`, `configs/b6_400m_win_v3.json` (win_v3 + `evidence_channels: 31` + chain block), `revision/scripts/b6/integration_4rank.sbatch`, tests `test_b6_{model,runtime,trainer,integration_contract}.py`.

**Model.**
- **Tracks.** The existing fusion is reused as is: `evidence_channels = 31` builds `evidence_proj` (`modeling_HyenaTransgenic.py:431-433`), which is added at `:551`.
- **Gather.** `B6TransgenicModel.forward` gathers right after downsample (`:749`) from (B, Lmax/6, 1536): `v = W_d·M[idx_d] + W_a·M[idx_a] + E_order + E_order_rev + E_slot + E_source + E_strand + w_count·log1p(units_bin)`. W_d and W_a are Linear 1536→512, the embeddings have 32/32/64/3/2 rows, and v is (B, 512, 512).
- **Chain block**, in a decoder-layer subclass after `encoder_attn_layer_norm`. Q is 1536→512 (win_v3 `d_model_decoder` = 1536), K and V are 512→512, with 8×64 heads, dropout 0.1 and out 512→1536. The update is `x ← x + tanh(α_l)·m·out` with `m = chain_mask.any(-1)`. α_l is set to 0 **after** `initialize_weights` (`:886`). The block drops with its layer under layerdrop, and non-reentrant checkpointing passes the chain tensors explicitly.
- **Finite when all masked.** Scores use `finfo.min`, and all-masked rows get zero attention weights **before** the m multiplication. A test asserts an exact 0 output and finite gradients; NaN·0 is not accepted.
- **Generation.** v and the mask are computed once with the encoder. `prepare_inputs_for_generation` (`:1047`) and beam expansion `repeat_interleave` them. There is no chain K/V cache, and `_reorder_cache` (`:1091`) is unchanged.

**Model acceptance** (eager fp32 eval). Also required: m = 0 contributes nothing under trained α; beam and greedy match per-step re-encoding; no recompile at fixed N_tok; DDP with chain-less ranks; α outside weight decay; a pad-invariant gather.
