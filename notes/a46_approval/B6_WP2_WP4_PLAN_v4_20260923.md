## 2. WP2 — rule 5 repair (Writer A)

**Files.** `src/transgenic/evidence/b6_corpus_repair.py` (imports `build_b5`/`gsf_contract` read-only), `revision/scripts/evidence/b6_build_corpus.py` (`--base --splits --flags --build-flags --seed --measure-only|--apply --out b5_full_b6_v1.db --freeze`, exclusive, no WAL), `b6_validate_corpus.py`, `tests/test_b6_corpus_repair.py`.

**Method.** Copy A40 and update rows in place without re-tiling, so `rn`, `wid`, order and coordinates stay A40's.
1. **Enumerate edge crossers explicitly.** `gc.genes_in_window` returns `(inside, partial_count)` (`gsf_contract.py:537-542`), not the partial genes. Use the same predicate as `gsf_contract.py:541` and `leakage.py:389-390`: `edge = [g for g in genes if g.end0 > ws and g.start0 < we and not (g.start0 >= ws and g.end0 <= we)]`.
2. **Population (D1).** For each kept train/valid forward tile, an edge crosser is a seed if the build's `leak` predicate (`build_b5.py:567`) or `hard` predicate (`:569`, A22 or A30) holds. Decoy is not applied. A strict-held-out-only population would waive orthogroup and hard-mask obligations, so it is not an option.
3. **Geometry = the rule 4(a) interval, no new RNG (D1 default, pending author confirmation).** WP1 already computes each genome-level component's exclusion interval: component span ± the **largest member flank the A40 build drew**, or 150 when no tile masked a member (`leakage.py:418-427`; flanks replayed at `:353-381`). The repair masks exactly that interval, clipped to the tile. The mask is component-level (A33.3) and equals C0's exclusion geometry, so **C0 exclusions do not change**; only provenance is revalidated (§8.3). v3's fresh `:b6edge:` draw is withdrawn, because it could exceed the historical flank and admit molecules touching the new mask (rule 4(b)).
   - **"Identical" covers the shared causes only:** `leak` → `test_orthogroup`/`heldout` (all) or `valid_orthogroup` (train_tiles), and A22 `hard` → `a22_hard`. There are two declared differences. A30-only components are masked with the same formula but get no rule 4(a) exclusion (`leakage.py:372-384`). A48 excludes every `edge_partial` span, including the unmasked gL.
   - **Historical geometry.** A40's per-gene flanks (`build_b5.py:600`, `leak_mask` `:654-663`) stay as built and are **grandfathered**, not claimed as literal A33.3 compliance.
   - **Author alternative.** A fresh per-component draw requires rebuilding C0 exclusions, HSPs, the merged DB, zero lists and caches first.
4. **Closure (A33.3).** Every labelled inside gene intersecting a final mask, including one reached only by the flank, is **unlabelled**. `gff` is regenerated via `gc.window_to_gsf_v3`, and tokens, `n_transcripts`, `qc` and `window_genes` are updated. There is no partial mask.
5. **One interval manifest.** `leakage.py` writes `b6-intervals-v2`, one row per (component, cause, scope), with fields in this fixed order: `manifest_version, species, chrom, component_id` (first member by (start0, gene_id)), `members` (sorted), `start0, end0, cause, scope, flank, flank_source ∈ {historical_max, fallback_150}, c0_exclusion ∈ {true, false}`.
   - **A30-only repair components** appear explicitly with `cause = a30_only` and `c0_exclusion = false`. They are never added to C0 exclusions.
   - **Canonical hash:** sha256 over UTF-8 JSON lines, one per row, with `sort_keys=True`, separators `(",", ":")`, rows sorted by (species, chrom, start0, end0, cause, scope, component_id), and the manifest version inside every row.
   - The hash is recorded in C0 provenance as `interval_manifest_sha256` beside `leakage_intervals_sha256` (`b6_build_c0.py:1840`) and in the freeze. The repair reads the manifest and never recomputes geometry. An older C0 is revalidated per §8.3.
6. **RC twin** = `revcomp` of the repaired forward tile, with GSF `gc.reverse_complement_v3` of the regenerated GSF.
7. **Measure first.** Two events change the row set: a train/valid tile over masked fraction 0.60 (`build_b5.py:602`), and closure removing the last labelled gene of a tile with an RC twin. `--apply` refuses if either is non-zero, because the train rows would leave 198,828, the basis of **N_pilot = 4,142** (P:999); **a further amendment is then required.**

**Outputs.** `b6_dna_repair(rn, wid, species_id, chromosome, start0, end0, component_id, cause, scope, flank, flank_source, is_rc)` and `b6_label_drop(rn, gene_id, cause)` in the B6 DB. The freeze JSON records `base_sha256` (A40), `out_sha256` (one sha for B6 and its comparator), `interval_manifest_sha256`, code sha, seed, input shas, rule id `rule5-leak-hard-c0interval-v1`, counts by species × split × cause, and row counts.

**Acceptance.** Byte identity is **B6 versus its comparator**. The A40 audit is exact: ACGT→N only inside repair spans, label changes only as `b6_label_drop`, and no test-tile change. On real data and fixtures:
- **Interval equality.** Every shared-cause repair span equals its manifest interval ∩ tile, byte for byte.
- **Molecule consequences.** Every C0 molecule with a placement overlapping a shared-cause span is `excluded_heldout` for scope all, or `train_tiles_excluded` for scope train_tiles in a train tile.
- A30-only spans and A48 `edge_partial` spans are reported as the two declared differences.

**Fixture** (`test_b6_corpus_repair.py`; its own world variant, WP1's fixture unedited). gL (`tests/test_b6_c0_world.py:16,45`) stays unmasked but A48-excluded. `gHE` is a strict held-out gene crossing a 30,720 edge, with historical max flank 60. A molecule at +40 nt is masked and excluded. A molecule at +100 nt stays admitted and unmasked; a fresh draw of 140 would have masked it while C0 admitted it, which is the counterexample the test guards. The fixture also includes an overlapping labelled gene (dropped by closure), an A30-only component (masked, not excluded) and a tile over 0.60 (`--apply` refuses).

Forward/RC consistency, byte-identical rebuilds and 198,828 real train rows are also required.

CDS phase from the alignment goes to `evlabel_phase` (phase is not a class). Protein never labels UTR.
- **UTR (A50/A50.1).** Candidate placements are same-strand, every CDS block inside a read block, and CDS introns equal to the read's introns over the CDS span.

Until then, `evlabel_provenance` records the policy and the consumer must refuse to treat the absence of boundary cells as a decision.
- **Merging.** Max across sources. Weight = `min(4, 1 + sw·g·log1p(n))`, with genotype per D10.

### 7.1 Track spec (K = 31, P:992)
- **Channels.** For s ∈ (EST, ONT, PacBio), channels 8s…8s+7 are `cov+, cov−, cov?, donor+, acceptor+, donor−, acceptor−, mask`. Channel 24 is protein CDS log1p(organisms), unstranded. Channels 25–30 are phase (0,+),(1,+),(2,+),(0,−),(1,−),(2,−).
- **Values.** float16 log1p(molecules): coverage is clipped at log1p(64); donor/acceptor sit on the boundary base.
- **RC** (`new[c] = old[perm[c]]`, then reverse L). Each source block uses the frozen `[1,0,2,5,6,3,4,7]` (+8s). Channel 24 is identity. The phase block is `[28,29,30,25,26,27]`: strand swapped, label kept (P:992).
- **Mask.** 1 iff the evidence owner's species has an admitted library of that source in the population, including at fraction 0 and at N. It is 0 when the source or its last library is withheld, or the tile is dropped.
- **Zeroing and C4.** All six phase channels are zeroed over the population's zero list (A48). In C4, count channels become 1.0 where > 0, and masks are unchanged.

### 7.2 Chain spec and `chain-rc-v1`
- **Elements.** 512; element 0 is the dummy (mask False, index 0, features 0) in slot 0, and chains use slots 1…63 (rule 6a).
- **Slot hash, exactly rule 6a.** `h(s) = int.from_bytes(hashlib.blake2b(f"{aug_seed}\t{row}\t{epoch}\t{s}".encode("utf-8"), digest_size=8).digest(), "big")` for s ∈ 1…63; π = slots sorted by `(h(s), s)`; the chain at fill rank r gets π[r−1]. `row` is the decimal `rn`, or the §7.4 window key at evaluation, where `epoch` = 0.
- **`chain_feat`** = (`order_fwd`, `order_rev` ≤ 31 in transcription direction, `slot` 0…63, `source` 0 EST / 1 ONT / 2 PacBio, `strand` 0 + / 1 −, `units_bin = min(units, 64)`).
- **Fill.** Long reads first, then EST, sorted by units ↓, intron count ↓, tie key ↑, then **PacBio < ONT**. (D8 keeps identical ONT/PacBio chains separate.) Tie key = `int.from_bytes(hashlib.blake2b(f"{species}\t{strand}\t{introns}".encode("utf-8"), digest_size=8).digest(), "big")`, where `introns` = `",".join(f"{d}-{a}")` over genomic (donor0, acceptor0) in transcription order. A chain that does not fit is dropped whole, and truncations are counted per source.
- **`chain-rc-v1`**, written and hashed: p → L−1−p; roles kept; strand swapped; order, slot and source unchanged. Twice = identity.
- **`CHAIN_SPEC_SHA`** covers every rule 9 item (P:997), including the §9 projections, both hash encodings and the source-order tie-break.

### 7.3 Draws (uniforms keyed to the recipient, resolved against the evidence owner)
- **Rank per draw.** Shards store `molecule_id`, never a rank. At load, the rule 8 rank is computed per requested `aug_seed`: 20260914 + seed for training (123 gives 20261037), and 20260914 + d for dose-response draw d ∈ 0…4.
- **Uniforms.** `u(p) = int.from_bytes(hashlib.blake2b(f"{aug_seed}\t{p}\t{row}\t{epoch}".encode("utf-8"), digest_size=8).digest(), "big") / 2**64`, for purposes p ∈ {`dropout, fraction, withhold_source, withhold_source_pick, withhold_library, withhold_library_pick`}.
  A `DrawSpec` holds only the recipient's six **uniforms**. Non-numeric purposes cannot collide with the slot key, and no `torch.Generator` is used (replacing `datasets.py:336-345`).
- **Resolution** happens in `resolve(draw, owner)`, where `owner` supplies the evidence owner's admitted sources and libraries. The owner is the recipient in every arm except C3, where it is the donor.
  `dropped = u_dropout < 0.5`; `fraction = {0.01, 0.1, 0.5, 1}[⌊4·u_fraction⌋]`. Source withholding fires if `u_withhold_source < 0.1` and picks `sorted(owner.sources)[⌊u·n⌋]` among EST/ONT/PacBio present (none present: recorded no-op). Library withholding works the same way over `sorted(owner.libraries)`, and withholding a source's last library zeroes its mask. EST withholding also removes phase; protein follows D7.
- Arms compare the **uniform log**, identical by construction; resolved identities are QC only. One resolved draw feeds both `rasterise` and `build_chains`, and `B6EpochSampler` yields (rn, epoch), so workers hold no state.

### 7.4 Contexts (two constructors, one type)
Both return `Context(row, species, chrom, ws, we, L, is_rc, kind ∈ {corpus, eval}, split, population, tile_exclusions, excluded_junctions, dna, dna_n_mask, zero_intervals, roles_scope, panel_locus)`.

**`corpus_context(corpus, rn, mode)`** serves train and valid tiles, with `row` = decimal rn and split from the corpus row. `train_track` excludes train-tiles-excluded molecules, `valid_track` admits them, and test tiles are refused. Chains split at 4(c) junctions, rule 4(a) tile intervals (including `edge_partial`), non-accepted junctions and tile edges.

**`eval_context(window, *, reference, panel, roles, generator)`** serves evaluation windows and needs **no corpus membership**. Z. mays has no B5/B6 corpus rows (`data/manifests/b5_excluded_species_v1.tsv:2`).
- **Verified identity.** The reference FASTA sha equals the evidence DB's `inputs.reference` sha. The panel sha is frozen (A. thaliana `b6_panels_v1.tsv` = `79367154…`, P rule 12; the Z. mays §9 locus list sha is recorded before first use), and `locus_id` is in the panel. (chrom, ws, we) must reproduce from a named generator: `centred30720-v1` = `mvp_windows.evaluation_window` (`mvp_windows.py:139`, fail-closed at edges), or `a27-tiles-v1` = `gsf_contract.tile_windows` (`:609`) at a recorded tier/offset. The window manifest is sha-bound.
- **Window key:** `row = f"eval:{species}:{chrom}:{ws}-{we}:{'rc' if is_rc else 'fw'}:{panel_id}"`. It keys every uniform and the slot hash, and contains non-digits, so it never collides with an rn.
- **Roles.** `eval_input` admits `b6_input` datasets only, by dataset/run. A. thaliana contributes `excluded_heldout` molecules whose primary placement overlaps the window's panel locus. Z. mays contributes M-EST (tracks and chains) and M-HQ18 (tracks only). A `b6_score` molecule is a hard error, and Z. mays in a corpus context is refused.
- **No rule 4 splitting and no masks** at evaluation (rule 6a; A33.3); chains split at window edges only, and DNA comes from the verified reference.
- **Z. mays evidence.** `b6_build_c0.py` needs `--corpus` (`:1707`) and refuses Z. mays training roles (`:150`, `:240`). `b6_build_eval_c0.py` therefore reuses its ingestion without a leakage model and publishes c0-v1 under policy `eval_only_no_leakage_model`, the `eval_only` family of §8.

**Zero lists (D4).** The producer at T covers only train_track (it drops train-tiles-excluded rows, `b6_routea_agreement.py:20-40`). `--population` writes one list per population (train_track, valid_track, eval_input) plus a QC JSON naming the population and its upstream shas. No b6_score molecule enters any list.

**C3 donor (D6).** Forward rows are sorted by `int.from_bytes(hashlib.blake2b(f"{aug_seed}\tc3\t{tier}\t{split}\t{wid}".encode("utf-8"), digest_size=8).digest(), "big")` and each is paired with the next, cyclically. The pairing is fixed, within (tier, split), with no fixed point, and twins share the donor. A (tier, split) group with fewer than 2 forward rows is a **build error**, reported with counts. The donor's evidence is resolved with the recipient's uniforms against the **donor's** admitted sources and libraries (§7.3), then RC-transformed iff the recipient is RC.

## 8. Hash binding (`b6_bindings.verify_inputs`; at every consumption **and every resume**)

**Typed required-key schemas.** The family is taken from the **verified** artefact's provenance policy (after its sha check), never from the caller. Each family has a fixed required-key set; a missing key fails, and there is no "if key exists" bypass (as there is at `b5_runtime.py:225`). A consumer declares the families it accepts.

| family (provenance policy) | required keys | accepted by |
|---|---|---|
| `training` (C0 with leakage model) | per (species, source): `inputs.corpus.sha256` = freeze `base_sha256` (C0 is built against A40, `leakage.py:362-367`); `leakage_intervals_sha256`; `interval_manifest_sha256` = freeze; B6 corpus sha = `out_sha256`; roles sha | training cache, trainer, resume; A. thaliana evaluation (its `eval_input` molecules live in this DB) |
| `eval_only` (`eval_only_no_leakage_model`) | reference FASTA sha = `inputs.reference`; roles sha; panel sha; window-manifest sha; eval-C0 sha + PROVENANCE; eval-only zero list | evaluation only (Z. mays); **training rejects it** |

Common to both families:
1. **Snapshots** (merged DB, B6 corpus, eval C0, side DBs). Refuse if `<file>.wal` exists (`open_published_c0`, `b6_build_c0.py:1141`). The recomputed sha must equal the sidecar/PROVENANCE sha and the recorded sha. Open `read_only=True`, then re-check that no WAL appeared.
2. **C0 content.** `verify_schema` (`c0_schema.py:394`) and every `c0_qc` leakage counter 0. For `training` only: A49.2 recomputed from `c0_meta.exhaustiveness` integers (C ≤ ⌊0.01·M⌋ per species × source; ΣC/ΣM ≤ 0.001 per species). Completeness policy `null_not_computed_at_c0` unless a WP2c DB is bound.
3. **Interval manifest (training).** A C0 lacking `interval_manifest_sha256` fails unless it is revalidated. "Projects exactly" is defined in three steps:
   - (a) Rerun `build_leakage_model` from the C0's recorded inputs and seed. Require the **complete** legacy row set, including test blocks, tile-specific masks, `edge_partial` rows and genome-level components with their `gene_id`/`tile_rn`, to reproduce `leakage_intervals_sha256` via `intervals_sha256` (`b6_build_c0.py:1829`).
   - (b) Take the manifest rows with `c0_exclusion = true`. Their projection (chrom, start0, end0, cause, scope) must equal, as a multiset, the recomputed **genome-level component** rows (`tile_rn` NULL, causes heldout/test_orthogroup/valid_orthogroup/a22_hard). Rows of other kinds are not expected in the manifest.
   - (c) A30-only rows must have `c0_exclusion = false` and must match no recomputed interval. Any mismatch fails; otherwise `interval_manifest_sha256` is recorded as revalidated.
4. **Zero lists.** The actual files and QC JSONs are rehashed against the cache manifest. The QC JSON's population and upstream shas must match the bound C0/merged shas, so a modified list fails even with unchanged cache bytes.
5. **Other.** The roles sha must equal its sidecar, and the cache manifest and shards are rehashed. The three spec shas (`AUG_SPEC_SHA` = `b6-aug-uniform-blake2b-v2`), aug_seed and draw set are recorded, and `evlabel: absent` is enforced.

**Acceptance.** `test_b6_bindings.py` removes each required key per family, and training rejects `eval_only` even with a corpus key present. `test_b6_eval_path.py` runs synthetic Z. mays eval C0 → eval cache → `eval_context` → batch **with no corpus file present**.
