## Authoritative requirements, not new choices

- **A11**, `revision/protocols/PROTOCOL_B1_frozen_v1.md:552–566`: accession versions are one accession; newest parsed version contributes support, aliases remain recorded. Normalized physical clone, including its 5′/3′ reads, is one molecule. Biological-library aliases refer to preparations, not batches/runs/plates. Without clone identity, counting collapse requires the same library, assembly, contig, strand and exact ordered CIGAR-derived blocks. Different libraries/structures stay distinct. Keep all originals/alignments; never impute adjacency or a junction between mates. Each molecule contributes once per junction; cap each library at ten molecules per junction. Accepted EST supports at most one locus; soft clipping supplies no evidence. Preserve accession/molecule/library/BioProject/signature/dedup IDs.
- **A21**, same file `327–334`: retained split pieces remain one A11 molecule; primary minimum is 100 nt. Record original retained intervals; do not join across removed vector sequence.
- **A46**, same file `973–976,981`: full member closure includes versions, mates and split pieces. Before rasterization, any excluded placement of any member excludes the entire molecule from training. This includes primary/supplementary and audit secondary-equivalent/ambiguous placements, either strand, all rule-4(a) interval classes—not just panel/test spans. Audit command uses `--secondary=yes -N 50 -p 0.5`; ≥50 secondary placements or MAPQ<5 outside exclusions makes a molecule unauditable/excluded. Required exhaustiveness is ≥99.9%, with the separately stated denominator of molecules with fewer than 50 placements; preserve/report both counts rather than conflating them. Shared excluded-gene junctions are excluded; leakage QC must be zero. Roles are `train_track`, `excluded_heldout`, `never`; only eligible held-out inputs may transition to inference, never to scoring the same locus.
