# B6 쉬운 설명 — TransGenic에게 전사체 증거를 가르치되, de novo 주석은 포기하지 않는다

이 문서는 연구실 누구나 읽을 수 있게 쓴 B6 계획 설명입니다. 정확한 동결 명세는
[`B6_EVIDENCE_MODE_WORKPLAN_v1.ko.md`](B6_EVIDENCE_MODE_WORKPLAN_v1.ko.md)(한글)과
[`B6_EVIDENCE_MODE_WORKPLAN_v1.md`](B6_EVIDENCE_MODE_WORKPLAN_v1.md)(영문 원본, v1.2; 2026-09-14 Codex 3회·Kimi K3 1회 검토)에 있습니다.
B6는 지금 학습 중인 시드 123 런을 전혀 바꾸지 않습니다.

## 1. 왜 하는가 (한 문단)

지금 TransGenic은 아홉 식물 게놈의 참조 주석만 보고 배웁니다. DNA를 읽고 유전자 구조를 씁니다. BRAKER·MAKER·PASA 같은
도구는 전사체 증거(EST, 장독)와 단백질도 쓰기 때문에, 증거를 한 번도 본 적 없는 모델과 비교하는 것은 공정하지 않습니다.
저자의 결정: 모델이 그 증거로부터 배우고, 그 증거를 쓸 수 있어야 한다. 동시에 TransGenic의 강점인 "서열만으로 주석"도
잃고 싶지 않습니다. 그래서 B6는 **모델 하나에 모드 둘**을 넣습니다.

## 2. 그림으로 보는 아이디어

```
              DNA 서열 ─────────────────┐
                                        ├──► HyenaDNA 인코더 ──► GSF 디코더 ──► 유전자 구조(텍스트)
  증거 트랙 (전부 0일 수도 있음) ────────┘
```

- **증거 트랙**: 염기마다 숫자 몇 개. "이 염기를 EST/장독이 덮고 있다", "여기 splice donor/acceptor를 분자 N개가 지지한다",
  "여기에 단백질이 정렬된다". 단편은 덮은 염기만큼만 세어지므로, 전사체를 완전히 조립할 필요가 없습니다.
  (EST의 90 % 이상이 단편이라 "EST 유래 isoform을 라벨에 추가"하는 초기 안을 버린 이유입니다.)
- **de novo 모드**: 트랙이 전부 0. 지금의 TransGenic과 똑같이 동작합니다.
- **증거 모드**: 사용자가 정렬한 EST·장독·단백질로 트랙을 채웁니다.
- **학습의 요령**: 학습 중 창(window)의 절반은 트랙을 무작위로 0으로 만들고, 나머지 절반은 증거를 무작위로 솎아냅니다
  (분자의 1 %, 10 %, 50 %, 100 %만 남김). 그래서 가중치 한 벌이 "증거 없음·조금·전부"를 모두 다루게 됩니다.
- 예측하는 것(GSF 텍스트)과 해독 방식(문법 제약, 타일링, 스티칭)은 바뀌지 않습니다.

## 3. 끝나면 말할 수 있는 것

1. 증거를 꺼도, 증거를 본 적 없는 모델보다 나빠지지 않는다(게이트 G1).
2. 증거를 켜면 주석이 좋아지고, 얼마나 좋아지는지를 "같은 유전자좌에서 증거 양을 바꿔가며" 곡선으로 보인다
   (dose-response, 게이트 G2).
3. 참조 프롬프트 완성 모드(논문의 주 모드)가 두 모드에서 모두 작동한다.

"B6는 B5에 증거만 더한 같은 런"이라고는 **말하지 않습니다**. 구조와 난수 흐름이 다르므로, 같은 모델에서 증거를
영구히 끈 대조 런이 계획에 들어 있습니다.

## 4. 어떤 증거를 어디에 쓰나

| 데이터 | 학습에 쓰나? | 결과 채점에 쓰나? |
|---|---|---|
| 학습 종 9종(애기장대 포함)의 EST, ONT, PacBio(Sequel II 이상), 단백질 | 예 | 애기장대 EST는 held-out 유전자좌에서만, "in-domain"으로 표기 |
| 옥수수·토마토(제외 종) | 절대 아님 | 예(옥수수가 주 검증 종) |
| 애기장대 검증 전용 장독(A-ONT1, A-HiFi) | 절대 아님 | 예(독립 tier) |

순환을 막는 규칙 두 가지:
- **학습으로 새지 않게.** held-out 유전자좌, test 블록, test orthogroup 유전자, 마스킹된 유전자에 — 게놈 어디서든, 어떤 정렬로든 —
  닿는 EST/리드/단백질은 분자 통째로 학습 트랙에서 뺍니다. secondary 배치를 남기는 별도 "감사" 정렬로 확인하고,
  개수는 QC 표에 적습니다(held-out 유전자좌에 남는 분자 수는 0이어야 함).
- **입력 증거 ≠ 채점 증거.** 검증 유전자좌마다 모델에 넣는 증거와 채점에 쓰는 증거를 다른 집합으로 미리 선언합니다
  (옥수수: 입력 = EST + 장독 세트 하나, 채점 = 나머지 장독 세트). 안 그러면 방금 보여준 것으로 채점하는 셈이 됩니다.

## 5. 작업 순서 (각 단계가 증명하는 것)

| 단계 | 내용 | 대략 | 증명 |
|---|---|---|---|
| **MVP pilot** (1주, 탐색) | 애기장대만, held-out 유전자좌 약 20개, 지금 시드 123 체크포인트에 증거 채널을 얹어 짧게 fine-tune, 증거 on/off, 시드 3개(≈ 20 GPU-h) | 1주차 | 채널이 효과가 있기는 한가? 없으면 여기서 중단 |
| WP0 | A46 개정 문안에 모든 값(시드, 해시, 명령, 유전자좌 패널, 임계값) 고정; 저자 승인 | 1일 | 규칙이 동결되기 전엔 아무것도 만들지 않음 |
| WP1 | 기존 정렬에서 증거 표(C0): 분자, 블록, 접합부, 체인, 역할, 출처 | 4~5일 | 논문의 옥수수 검증에도 필요 |
| WP2 | 누출 배제 + 창 가장자리 마스킹 결함 수리; 학습 코퍼스 재빌드 | 3일 | 누출 0인 QC 표 |
| WP3 | 증거 트랙, 솎아내기, 가장 큰 창(129 kb) 메모리 벤치 | 2일 | 합친 모델이 GPU 메모리에 들어감 |
| WP4 | 모델 변경(선형 투영 하나, bias 없음) + 트레이너 + 4-GPU 시험(캐시 디코딩 포함) | 2~3일 | 트랙 on/off에서 학습·디코딩이 동일하게 동작 |
| WP5 | 사전 등록 패널에서 pilot: B6 vs 증거 off 대조 vs 서열 전용 대조 | 3~4일 | 게이트로 go/no-go |
| WP6 | 본 런(B6, 증거 off 대조, 서열 전용 대조; 짧은 대조 2개) | 큐 포함 1~2주 | 보고할 모델 |
| WP7 | 두 모드 평가, dose-response, 옥수수/애기장대 검증 | 1주 | 표와 그림 |

MVP 이후 총 5~6주. GPU: 본 런에 현재 배정보다 약 350 GPU-h가 더 필요하거나, 서열 전용 대조를 빼고 시드 123으로 대신합니다.

## 6. 저자가 정해야 할 것 (WP6 전까지)

1. 약 350 GPU-h 보충 vs 재빌드 서열 전용 대조(C1') 생략 후 시드 123을 비교군으로.
2. abstract를 이끄는 모델: B6 de novo 모드 / B6 증거 모드 / B5.
3. 옥수수에서 어느 장독 라이브러리가 입력이고 어느 것이 채점인지(제안: 입력 = M-EST + Wang 2018 HQ isoform; 채점 = Wang 2020 FLNC + root-tip ONT).
4. EST 121 nt arm도 입력 트랙에 쓸지(제안: 채점 표에만).

## 7. 진행 확인 방법

- 시드 123(B5) 상태와 B6 단계는 런 로그와 이 저장소의 프로토콜 개정에 기록됩니다.
- 위 각 단계에는 상세 계획에 검증 항목이 있고, 그 검증을 통과해야 "완료"입니다.
- 검토: Codex 1~3차와 Kimi K3 challenge 요약은 상세 계획 머리에, 원문 기록은 세션 노트에 있습니다.
