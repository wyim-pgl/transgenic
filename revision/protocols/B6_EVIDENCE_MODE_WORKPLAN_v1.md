## 1. Goal and claims
- B5 (seed 123, running): the split-only retraining — reference GSF labels, sequence-only input. It stays the comparator for the leakage/context change and is **not modified** (A28).
- B6: the same recipe plus an optional per-nucleotide **evidence channel**. Trained with channel dropout so one set of weights supports
  - **de novo mode**: channel all-zero → sequence-only annotation; compared with Helixer/Tiberius and with B5;
  - **evidence mode**: channel filled from the user's aligned ESTs/long reads/proteins → compared with BRAKER/MAKER/PASA-class tools.
- Claims we will be able to make: (i) evidence-trained weights do not degrade de novo annotation beyond a pre-declared margin; (ii) supplying evidence at inference improves annotation, with a measured dose-response at fixed loci; (iii) completion mode (reference-prompted) works in both modes.
- Claims we will NOT make: runtime/result neutrality between B5 and B6 (they differ in architecture and RNG; see controls), independence of A. thaliana ESTs (in-domain, locus-disjoint) [C1-8].

## 2. Definitions to FREEZE (A46)
1. Evidence sources and roles (A14 unchanged): training-side = nine training species' ESTs (A21-screened, A37 primary arm ≥ 100 nt; the ≥ 121 nt arm is a paired sensitivity arm wherever an EST-derived quantity is reported), ONT, Sequel II+ PacBio, protein alignments (A19/A43). Never: Z. mays, S. lycopersicum, A-ONT1, A-HiFi. Amends A9 (option J is now in scope as B6) and the scope sentence of A18 [C2-13].
2. Observation schema = full C0 (IMPLEMENTATION_ORDER_B5_C0_C2_v1.md:34), plus for route B an `est_protein_hsp` table (est molecule_id, protein_id, protein_source ∈ {orthodb, swissprot}, protein_species, est_start, est_end, frame, evalue, bitscore, projected genomic intervals with phase) with provenance (diamond version, database sha256, command): `evidence_alignment`, `molecule_member`, `aligned_block` (ordered within a molecule), `junction_observation` (raw and ±3-nt-corrected coordinates for ONT, A20), `partial_chain`, `partial_chain_intron`, `junction`, `junction_support`, `chain_junction`; every row carries source, library, genotype stratum, role (`training_eligible` / `validation_only`), and provenance hashes [C1-9, C2-9].
3. Molecule unit: EST = A11 clone-merged unit including all accession versions, mate reads and UniVec split parts; long read = A16 unit. Protein: the SUPPORT-COUNT unit is the OrthoDB organism (A19), but the LEAKAGE-CLOSURE unit is the protein query sequence (all its alignments, A43 mapping_ambiguous included) [C3-3]. A molecule is one unit everywhere it appears [C1-7].
4. Leakage exclusion (observation-level, before any raster) [C1-4, C1-5, C2-3, C2-5]:
   a. Excluded intervals per species: strict held-out loci ± their seeded flank (A33: 50–150 nt, the exact seeded value per locus), test blocks (A29), genes of test orthogroups and, for training tiles, of valid orthogroups, A22 hard-flagged genes, A33 overlap components and decoy-masked genes, the `partial` span of any edge-crossing gene in a tile.
   b. A molecule unit is dropped from ALL training-side tracks if any placement of any member (primary, supplementary, secondary-equivalent, `mapping_ambiguous`) overlaps an excluded interval on either strand. Because the frozen §3 command runs `--secondary=no` (est_align.sbatch:144), placements are recovered by a dedicated audit alignment used ONLY for exclusion, never for labels: the frozen §3 command with `--secondary=yes -N 50 -p 0.5` plus, for every retained molecule, a direct interval test of its primary/supplementary placements; a molecule with ≥ 50 secondary placements, or any placement with mapq < 5 outside an excluded interval, is treated as unauditable and excluded. The audit's exhaustiveness is reported as the fraction of molecules with fewer than N placements (must be ≥ 99.9 % per species, else N is raised and the audit rerun) [C2-7, C3-3].
   c. Junction support at coordinates shared by an excluded gene and a neighbour is excluded [C1-5].
   d. QC table (A16 completeness): per species/source — molecules in, excluded by cause (a–c), retained; for A. thaliana: molecules overlapping held-out loci = excluded count (retained must be 0).
5. DNA masks: the tile builder's gene-containment mask leaves edge-crossing held-out DNA exposed (build_b5.py:561-567). B6 repairs this by masking the exposed span ± flank in train/valid tiles [C2-4]. B6 and the zero-track architectural control C2 use ONE repaired DuckDB file (`b5_full_b6_v1.db`) and the same `rn` order; geneList/window_genes/tile_blocks are byte-identical by construction, one sha256 is recorded, and C2 logs `evidence_channel=off` [C3-3]. **C1' is not run.** C1 (B5 seed 123) remains on the unrepaired corpus; its DNA-mask difference is quantified beside every B5-vs-B6 comparison, not claimed to be identical.
6. Tracks (per nucleotide, float16, built per tile from retained observations; observation→tile membership is kept so thinning re-rasterises) [C2-3]. Thinning rule (frozen): each retained molecule gets `rank = int.from_bytes(blake2b(f"{aug_seed}\t{species}\t{molecule_id}".encode("utf-8"), digest_size=8).digest(), "big") / 2**64` (hashlib.blake2b, fixed byte encoding — never Python's salted built-in `hash()`, which would break replay across processes [K-3a]); a draw at fraction f keeps molecules with rank < f, so draws are nested by construction; ties are impossible and no rounding is applied [C3-3]:
   - per source (EST, ONT, PacBio) × strand: transcribed-block coverage log1p(molecules), clipped at log1p(64);
   - per source × strand: donor and acceptor support log1p(molecules) on the boundary base;
   - unknown-strand coverage (unoriented ESTs) per source;
   - protein CDS coverage log1p(organisms);
   - **phase channels (author decision 2026-09-14, route B primary)**: EST-derived reading frame — each screened EST is aligned to cross-species proteins with `diamond blastx --frameshift 15 --evalue 1e-5 --min-orf 30 --max-target-seqs 25` (diamond ≥ 2.1.24) against the frozen OrthoDB v12 Viridiplantae set (A19) plus the Swiss-Prot reviewed Viridiplantae set (A30, sensitivity arm, counted separately in QC); each HSP ≥ 30 aa gives the EST a frame over its aligned span; the frame is projected onto the genome through the EST's spliced alignment (recomputed across every intron by intron length mod 3; HSPs whose frame is inconsistent within one EST after projection are dropped) → six channels phase {0,1,2} × strand {+,−}, value log1p(EST molecules); route A cross-check: the miniprot CDS blocks of the same cross-species proteins give a genome-derived phase; where A and B disagree on a base, both phase channels are set to 0 (neutral) and the disagreement is counted in QC. Same-species proteins are never used (A19 cross-species rule) — a species' own Swiss-Prot/TAIR-derived proteins would re-encode its reference annotation; protein queries touching excluded intervals are removed molecule-wide (§2.3 leakage-closure unit) [K-author];
   - source-availability mask per source (1 if the species/library has that source at all; dropped together with the source under dropout).
   No reference-derived feature (no annotation-based junction snapping, no phase from the reference), no tile-wise normalisation [C2-Q5]. A18.4 weights are not used as input multipliers; counts and genotype/QC flags are separate channels.
   RC tiles: coordinates reversed; donor/acceptor identity kept, strand channels swapped (tests/test_gsf_rc.py:26) [C2-new4].
7. Model: `E = E_seq + Linear_noBias(K → d)(tracks)` applied to HyenaDNA's per-nucleotide states before the downsampling/skip path (modeling_HyenaTransgenic.py ~725) [C2-Q1]. Decoder, tokenizer, GSF target, grammar-constrained decoding (A24), tiling/stitching (A27) unchanged. Zero tracks ⇒ exact sequence-only path.
8. Training: loss = L_GSF only. Channel dropout p = 0.5 per tile (frozen). When kept, the retained-molecule fraction is sampled uniformly from {0.01, 0.1, 0.5, 1} with a separate augmentation RNG stream (`aug_seed` = 20260914 + seed; recorded); source-withholding (drop one source entirely) at rate 0.1 and library-withholding at rate 0.1 of kept tiles [C3-2]. Stop rule: minimum de novo-mode validation L_GSF, patience 3, ceiling 22 (A18.6); one checkpoint (that best) is used for both modes; evidence-mode validation L_GSF is logged as a diagnostic [C2-Q4].
9. Runtime identity adds: evidence DB sha256, track spec hash, p, thinning set, `aug_seed`, withholding rates, tool versions and exact commands (minimap2, samtools, blastn, DuckDB, torch, accelerate), and the compile policy; resume whitelist extended (src/transgenic/training/b5_runtime.py:224). Compile-fallback policy: a Dynamo fallback to eager is a FAILURE of the run (the trainer must raise, not warn — train_HyenaTransgenic.py:317 today only warns); memory-abort ceiling: any rank exceeding 110 GB reserved aborts the link (marker `MEMORY_ABORT`) [C3-2, C3-3].
10. Validation evidence allocation [C2-new1, CRITICAL]: at every validation locus the evidence supplied as model INPUT and the evidence used to SCORE are disjoint sets, declared before inference and written into DATASET_ROLES (`b6_input` / `b6_score` columns, hashed). Role-transition rule [C3-4]: a training-species molecule is in exactly one of three states — `train_track` (retained in training tracks), `excluded_heldout` (dropped from training because it touches an excluded interval), or `never`; ONLY `excluded_heldout` molecules of input-eligible sources (A-EST, A-ONT2) may be supplied as INPUT at the held-out loci they touch, and a molecule used as input at a locus is never used to score that locus. Z. mays — input = M-EST + M-HQ18 (Wang 2018 HQ isoforms); scoring = M-FLNC (Wang 2020) + root-tip ONT (PRJNA822071), tier 1; the input set is never scored. Because M-EST and RefGen_V4-derived transcript references are not independent of the reference annotation, any F1 against RefGen_V4 is labelled `reference-dependent`; the independent outcome is complete-chain support by the scoring set (§9 P1–P5). A. thaliana strict held-out loci — input = `excluded_heldout` A-EST + A-ONT2 (in-domain, locus-disjoint); scoring = A-ONT1 + A-HiFi (validation-only). Locus panels (A46 rule 12): one seeded shuffle (20260914) of 2,079 eligible nuclear, multi-exon (≥ 1 intron), non-overlapping, non-hard-flagged held-out loci yields three disjoint panels: MVP 50 (core 20 + 30), pilot 300, final 1,729. `71_b6_panels.py`, `72a_est_molecules_per_locus.sh` and `72_mvp_select_loci.py` define the eligible pool, primary-placement counts and assignment; panel ids/counts/hashes are recorded before A46 approval. MVP requires length ≤ 20 kb and ≥ 3 distinct primary placements; skipped loci remain eligible for pilot/final. Power is descriptive: estimate the 80%-power minimum detectable F1 difference from WP5 pilot variance and report it there; no power calculation gates approval or go/no-go. This supersedes the earlier 1.0-point power prerequisite [K-2b].
11. Controls (pre-declared, same corpus, same initialisation, same data order, separate augmentation RNG) [C1-3, C2-Q2]:
   - C1: B5 seed 123 (existing, unrepaired-mask corpus) — historical comparator;
   - C1': sequence-only run on the repaired corpus — **not run (author decision 2026-09-14: C1 is the sole sequence-only comparator; the DNA-mask difference between the unrepaired and repaired corpus is quantified and reported)**;
   - C2: B6 architecture with tracks permanently zero (p = 1), **full duration**;
   - C3: shuffled-evidence (tracks from a different tile of the same tier), matched budget;
   - C4: presence-only tracks (binary), matched budget;
   - C5: evidence-only reconstruction baseline (Protocol M splice-graph + ORF rule, no model) at the validation loci;
   - C6: phase channels zeroed (matched short run) — contribution of the route-B phase channels.
   Matched budget (A46 rule 11): **N_pilot = 4,142 optimizer updates**, seed 123 for B6/C2/C3/C4/C6, `aug_seed = 20261037`. B6 and C2 archive their exact step-4,142 checkpoints; compare them with the final step-4,142 C3/C4/C6 checkpoints on the pilot panel only, never with best-validation checkpoints. Full-run final evaluation keeps the best-validation policy of §2.8.
12. Dose-response [C2-new2]: at a fixed panel of validation loci, evidence is thinned in nested subsets (fractions 1, 0.5, 0.1, 0.01, 0; 5 random draws each, same draws across modes) and re-rasterised; metrics per fraction with paired locus-bootstrap intervals. Coverage-bin summaries are descriptive only.
13. Gates (pre-registered, frozen in A46) [C2-Q7, C3-5]: metric = transcript-level F1 per GFFCompare v0.12.6 exact intron-chain match (monoexonic: exact CDS), pooled over the frozen final panel (§2.10), denominator = all reference transcripts of panel loci for recall and all predicted transcripts for precision, identical for every arm; paired locus bootstrap, 2,000 replicates, seed 20260914, percentile 95 % interval. (G1) de novo mode: lower bound of (B6 − C2) ≥ −1.0 percentage point. (G2) evidence mode: lower bound of (evidence − de novo) > 0 AND lower bound of (evidence − C5) > 0, where C5 is evaluated on the same panel with the same input evidence set and the same denominator (loci where C5 emits nothing count as zero recall, not as excluded). (G3) grammar: `validate_gsf` violations per 1,000 predicted transcripts ≤ B5's value AND transcript recall ≥ 0.9 × B5's recall in the same mode, so an empty or minimal output cannot pass. Abort rules: any leakage QC count ≠ 0, replay/RC/resume determinism failure, Dynamo fallback, memory abort. Author decision (2026-09-14; A46 decision 1): headline = B6 de novo, evidence mode alongside it, B5 seed 123 as the supplementary legacy comparator. G1 failure restores B5 as headline; G2 failure alone keeps B6 de novo as headline and withholds only the evidence-mode claim, while reporting its numbers. The MVP has no bearing on this fallback.
14. Reporting: A37 paired arms for every EST-derived number; both modes in every B1-era table; the dose-response figure; the completeness/leakage QC table; the training-coverage vs test-coverage distribution.
